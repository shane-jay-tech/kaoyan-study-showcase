# 核心闭环深度重建：从视觉外壳到可完整演示的作品

日期：2026-09-01
状态：已实现并发布

## 原始需求

用户反馈公开站“只是一个空有表面的模板”，希望它像自己正在使用的学习系统一样可完整展示。经用户选择，确认范围是：

- 实现深度：先做深核心闭环（首页、计划、学习、练习、复盘、数据分析、能力诊断）。
- 内容结构：单目标三轨（专业主线、语言训练、公共基础），不出现真实院校/专业方向代码。

## 决策

在现有公开镜像上重建本地确定性引擎，不搬运私有系统代码或数据：

- 数据仍由 `src/data/public-source-mirror.ts` 唯一维护：43 个知识点、9 章、22 道题库、20 张复习卡、8 条错题、5 天计划模板、微课与诊断样本。
- 状态仍由 `src/lib/demo-state.ts` 唯一维护：练习会话、复习卡组、错题本、微课进度、跨日计划、周复盘与诊断报告都在内存 reducer 中。
- 页面组合保持 `MirrorPages.tsx` 作为唯一公开入口，内部按路由族拆分到 `pages/`，共享原语在 `primitives.tsx`。
- 主观题评分、复习间隔、诊断建议全部由本地确定性规则计算，不调用任何在线模型。

## 关键工作流

- 计划：日期切换、容量约束、开始/完成/延后/跳过/拆分、周复盘。
- 学习：三轨章节进度由知识点状态汇总；微课核对推进状态；掌握验证把焦点带入练习。
- 练习：单选/多选/简答/默写四类题型，按答案或采分点确定性评分，逐题回顾并回写错题本。
- 复盘：0-5 分级确定下次间隔，失败卡暂停/恢复，错题延迟复测与补救练习。
- 分析与诊断：趋势、薄弱点、能力雷达由会话状态计算；诊断三步生成报告并把建议任务写回计划。

## 验证记录

- 本地：typecheck、lint、39 个单元测试、20 个浏览器测试（19 通过 + 1 个按设计跳过）、生产构建全部通过。
- 附件：PDF 832,175 bytes（5 页可选文本）；ZIP 2,983,714 bytes；SHA-256 清单与本地/线上一致。
- 隐私：`npm run audit:privacy` 扫描源码、dist、PDF 文本、ZIP 清单与内容共 81 个文本面通过；截图 OCR 因本机缺少 `tesseract + chi_sim` 如实记为 SKIP。
- 线上：GitHub Actions `33421409694` 成功；桌面和移动各 17/17 路由可见、无横向溢出、无外部请求、无控制台或页面错误。
- 认证、迁移、readiness：对无账号、无持久化的静态公开镜像为 NOT APPLICABLE，未伪造通过。

## 边界与残余风险

- 真题、模拟考试、系统状态与内容治理仍保留上一版简化展示，后续按需单独深化。
- 没有授权的私有系统登录态渲染截图，像素级私页对照仍不可用；视觉结论基于只读源码基线与公开 DOM/截图/尺寸断言。
- 刷新页面会回到同一套虚构初始场景，这是公开演示的既定边界，不是数据丢失缺陷。
